## 🎯 Problem Statement Alignment

Built specifically for **Problem Statement 1: The Interview Agent**.

* **Contextual Interview Setup:** Generates dynamic, context-aware technical questions based on candidate profile and domain focus.
* **Continuous Speech Recognition:** Custom speech-to-text logic using Web Speech API that allows users to pause and think without auto-submitting answers.
* **Real-time Evaluation:** Provides immediate AI feedback on candidate responses and dynamically routes to follow-up questions.
* **Interactive Scorecard:** Visualized `/report` dashboard featuring skill competency breakdown graphs, communication metrics, and full Q&A transcripts.

---

## ✨ Key Features

* **Contextual Interview Setup:** Tailors questions based on target roles, job descriptions, and candidate profiles.
* **Continuous Speech Recognition:** Speech-to-text logic that allows users to pause and think without auto-submitting answers.
* **Real-time Question Evaluation:** Glassmorphism pop-up modal providing dynamic performance feedback and next-question routing.
* **Interactive Evaluation Scorecard:** Comprehensive `/report` dashboard featuring skill competency breakdown graphs, communication metrics, and full Q&A transcripts.

## 🛠️ Tech Stack

* **Framework:** Next.js (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS, Lucide React Icons
* **AI & LLM Integration:** Google Gemini API
* **Voice Processing:** Web Speech API (Continuous Recognition Mode)
* **Data Visualization:** Chart.js, React-Chartjs-2
* **Deployment:** Vercel
